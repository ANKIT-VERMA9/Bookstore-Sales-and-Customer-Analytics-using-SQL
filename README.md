# 📚 Bookstore Sales and Customer Analytics using SQL

## 📌 Project Overview
Analyzed bookstore sales and customer data using SQL to identify sales trends, customer behavior, and top-performing books.

## 🛠️ Tech Stack
- SQL (MySQL)
- CSV Files
- Relational Database

## 📊 Data Source
- Kaggle Dataset
- CSV File Format

## ✨ Features
- Customer and sales analysis using SQL queries.
- Used Joins, Aggregate Functions, and Subqueries.
- Identified top-selling books and valuable customers.
- Generated business insights from sales data.

## 🚀 Conclusion
This project demonstrates practical SQL skills including database design, joins, aggregations, and business analytics for Data Analyst roles.
